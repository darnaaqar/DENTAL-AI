# Dental AI Clinic - Android APK Build

This repository is configured with GitHub Actions to automatically build an Android APK file.

## How to Get Your APK File:

1. **Automatic Build on Push:**
   - Every push to `main` or `master` branch triggers the **Build Android APK** workflow automatically.

2. **Manual Run (Workflow Dispatch):**
   - Go to your GitHub repository in browser.
   - Click the **Actions** tab at the top.
   - Click **Build Android APK** in the left sidebar.
   - Click the **Run workflow** dropdown on the right side and press **Run workflow**.

3. **Download Your APK:**
   - Click on the completed workflow run.
   - Scroll down to the **Artifacts** section at the bottom.
   - Click on **DentalAI-Clinic-APK** to download the zip containing your `.apk` file!
